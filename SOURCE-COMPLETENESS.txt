Chinesium X99 SecureBoot Patcher v0.967 source package

Complete source, caller-owned BIOS helper reply files, separate cleanup and
helper failure diagnostics, hardware-free packaged helper exchange test,
Windows medium/elevated token regression, exact-tool inventory/downloader,
normal-privilege GUI with file drops, isolated Windows build and runtime checks.

External firmware tool binaries are not redistributed. The GUI downloads
and verifies the four required files on demand into tools beside the EXE.
This is source, not precompiled Windows executables.

Build: RUN-SETUP-AND-BUILD.cmd. Rebuild both EXEs when upgrading.
Validation and Windows integration limits: VALIDATION-v0.967.txt.
