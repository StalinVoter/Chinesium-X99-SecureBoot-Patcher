UEFIReplace 0.28.0 for Windows is required but is not redistributed by this project.

Official project:
https://github.com/LongSoft/UEFITool

Official 0.28.0 release:
https://github.com/LongSoft/UEFITool/releases/tag/0.28.0

Exact Windows archive:
https://github.com/LongSoft/UEFITool/releases/download/0.28.0/UEFIReplace_0.28.0_win32.zip

Extract UEFIReplace.exe from that archive and place it in this folder:
  tools\UEFIReplace.exe

Required SHA-256 of UEFIReplace.exe:
ab05d53fcac19651818f4ee4505813b10badec7a10d141836fff3bba8964ed8b

The patcher refuses any UEFIReplace.exe whose SHA-256 does not match this value.
