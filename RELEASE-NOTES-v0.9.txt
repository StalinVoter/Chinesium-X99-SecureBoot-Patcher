X99 Secureboot Patcher v0.9 release notes
=========================================

v0.9 is the first public-preview version of the dedicated X99 Secure Boot
certificate patcher.

Core behavior
-------------
- Inspect AMI Aptio-style X99 firmware factory-default PK, KEK and db variables.
- Automatically identify which of the three need updating.
- Replace only validated targets with exact bundled Secure Boot update FFS files.
- Preserve a non-test production/OEM PK rather than replacing it merely because
  it differs from the bundled update payload.
- Preserve untargeted Secure Boot firmware data.
- Never overwrite the input ROM; create a new output image.

Compatibility
-------------
The implementation is structure-driven rather than board-name-driven. It
validates the AMI Freeform FFS, GUID-defined LZMA container, raw authenticated
variable and EFI signature-list layout before permitting a patch.

The regression corpus includes PANDL X99-XD3 compact/classic, MACHINIST X99-V9S,
Qiyida X99-K9S and Jginue X99 firmware.

Silent rebuild safeguard
------------------------
The application records valid FIT-to-microcode relationships before Secure Boot
firmware-volume rebuilding. If the rebuild moves a referenced microcode, it
retargets only the relationship affected by this operation.

For an already-stale input, the original stale displacement to the same exact
microcode identity is preserved; the app removes only additional displacement
introduced by its own rebuild. Ambiguous cases fail closed.

There is no FIT status, warning, control or terminology in the GUI.
