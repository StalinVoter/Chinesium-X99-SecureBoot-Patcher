The Windows build automatically performs the first two Windows steps and
refuses to create a new release ZIP unless every packaged launch test passes
for the exact EXE hashes. TEST-WINDOWS-SANDBOX.ps1 provides the separate
offline clean-Windows test; results must be checked after running it.

FIT implementation remain byte-identical to v0.964. FPT and UEFIReplace
process creation uses the new external-process DLL-directory wrapper.
